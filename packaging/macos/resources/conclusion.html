Project Hoopeo is installed

  • Open Hoopeo Studio from Applications. Session > Open Demo Clinic tries it without setting anything up.
  • Open DEP CLI from Applications for a shell, or run dep-cli --help in Terminal.
  • If DEP Engine runs in the background, the admin password is in ~/Library/Application Support/Project Hoopeo/admin-password.
  • To remove everything: sudo /usr/local/share/project-hoopeo/uninstall.sh. Your databases are kept.
