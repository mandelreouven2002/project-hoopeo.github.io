Project Hoopeo

Database-Enforced Privacy. Version __VERSION__.

This installer can add:

  • Hoopeo Studio: the developer application for DEP SQL, with DEP Engine built in.
  • DEP CLI: the command-line tool dep-cli, with DEP Engine built in, and the DEP CLI app, which opens it in Terminal.
  • DEP Engine server: dep-engine, for applications and tools that connect over the PostgreSQL wire protocol, optionally running in the background.
