# Contributing

This repository is private and is not open to contributions. It holds the source of DEP Engine, DEP CLI and Hoopeo Studio, and the packaging and release workflows of Project Hoopeo.

Contributions to the open layers (the specification, the documentation, DEP.js and the playground, the examples, the website) go to the public repository, <https://github.com/mandelreouven2002/project-hoopeo.github.io>, under the licenses described in [`LICENSING.md`](LICENSING.md).
