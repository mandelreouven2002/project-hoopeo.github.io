Database-Enforced Privacy (DEP)

Privacy rules that the database enforces on every query

DEP is a way of building a database so that the engine itself enforces privacy rules for every client. A protected value can be used to find and to join records, and an ordinary query never gets it back.

The same lookup, three outcomes

Find a patient by ID number, without being handed the ID numbers

Reception types the ID number a patient presents. A regular database answers with the row, ID number included, and the same privilege lets the next query read every ID number in the table. DEP matches the number through a blind index and returns the column as NULL. A query that would link every patient to every diagnosis is refused before it reads a row.

The second and third panels are the real output of DEP Engine on the demo clinic. The concepts guide explains each rule.
